# Module 5 — Complete the full-stack application

[Project overview](../README.md) · [Workflow](../STUDENT_WORKFLOW.md) · [Rubric PDF](../rubrics/PromptLab_Module_5_Project_Rubric.pdf)

Continue from your Module 4 application. Implement the remaining feature, normally tagging, and build the frontend yourself.

1. Implement the second backend feature and any additional endpoints test-first, preserving red/green commits. Keep both feature specs and API documentation current, and retain meaningful coverage across the completed backend.
2. Complete and commit specs/frontend.md before generating React code. Define journeys, components, state ownership, API mappings, loading/empty/error behavior, validation and keyboard/mobile use. Each specified component must have its own module.
3. Build React against your real API. Support list/detail/create/edit/delete with confirmation, collection management/filtering/search and access to the versioning/tagging functionality. Verify recovery paths as well as successful actions.
4. Provide reproducible full-stack deployment or a documented full-stack container run. Create the needed frontend build/container configuration; the initial starter supplies none. Document commands, ports, variables, production API routing, secret handling and the in-memory reset limitation.
5. Run the backend suite against the deployed configuration and verify the frontend's real API journeys. Record actual scaffold-to-first-passing-new-backend-endpoint timestamps and blockers as you work.

Record spec-before-code and test-first commit references, journey results, deployment/run instructions, configuration checks and timing evidence in EVIDENCE.md.

The source's four-hour timing figure is unvalidated. Pilot calibration and criterion versioning must precede any timing-based Not Yet. Missing calibration does not automatically award Met; record the evidence honestly. This is not a four-hour limit for the entire application.

**Criteria:** C3.1–C3.5. C3.3 is MUST PASS. Mark the snapshot `module-5-complete`. Keep your completed app for the Module 6 defense; there is no weekly upload.
