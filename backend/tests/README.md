# Your product tests

Write your own tests as required by the [module guides](../../README.md#your-milestones). No grading tests are supplied in this starter.

With the virtual environment active, run tests from `backend/` with `python -m pytest`. At the initial handoff there are no test files; a no-tests-collected result is expected at that point and is not a passing suite.

Preserve meaningful failing-test commits before implementation, actual results and the corresponding passing commits in [EVIDENCE.md](../../EVIDENCE.md). Build meaningful coverage rather than tests that merely execute lines.
